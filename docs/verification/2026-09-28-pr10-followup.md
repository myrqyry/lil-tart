## Additional current-review fixes

The updated Kilo summary (06:08 UTC) and Codex review of `a3dfeb4` revealed newer
issues in the same work:

- Encoder and ColBERT keep a pending tokenizer in a local variable until the model
  load passes its disposal guard. A late tokenizer cannot repopulate disposed state.
- All three pipelines reject `load()` after disposal with `CANCELLED`, even if an
  earlier inference had reported readiness. Run completion preserves disposed status.
- Text disposal clears references and records disposed status before asynchronous
  cleanup, attempts both conversation and engine deletion, and reports cleanup
  errors. A rejected late-engine deletion is attached as the cancellation's cause.
  This does not guarantee native memory was released when the native API rejects.
- Malformed base input cannot trigger scoped deletion. Insufficient legacy cache
  metadata is visible as unverified, excluded from current-base stored counts, and
  protected from pruning/scoped deletion. Registered paths can establish membership
  when a model is loaded. The existing explicit Clear action is labelled Clear all
  and remains available even if only legacy/orphan bytes exist.
- Changelog scope and streaming comments now match the implemented behavior.
